# actividad2_POO
Aplicación simple de gestión de Estudiantes en Java que incluye la declaración de clases, instanciación de objetos, y uso de métodos y constructores.
# Sistema de Gestión de Estudiantes

## Descripción
Aplicación Java simple para gestionar estudiantes y cursos, desarrollada como parte de la Actividad Formativa 2.

## Características
- Gestión de estudiantes con información personal y académica
- Gestión de cursos con múltiples estudiantes
- Operaciones CRUD (Crear, Leer, Actualizar, Eliminar)
- Cálculo de promedios y estadísticas

## Conceptos Aplicados
- Programación Orientada a Objetos (POO)
- Declaración de clases y atributos
- Instanciación de objetos
- Constructores (por defecto y parametrizados)
- Métodos getters y setters
- Métodos de instancia
- Colecciones (ArrayList)
- Encapsulamiento

## Cómo Ejecutar
1. Clonar el repositorio
2. Compilar los archivos Java
3. Ejecutar la clase Main
